# Midnight Sway Atomic Icon Set

This is a near-complete replacement icon set for Fedora Sway Atomic's default Adwaita, Adwaita Legacy, and hicolor icons. Adwaita's default `cursors` directory has not been replaced, so it remains the active cursor theme. A small number of other default icons have also been preserved where they already fit the rice.

Most icons, however, have been replaced because they were heavily skeuomorphic or otherwise visually inconsistent with the rest of the system.* This icon set is still a first draft, but a fairly complete one. Over time, the icons will, where possible, be made sleeker, simpler, and more professional. Only a few currently meet that standard.

The bane of any set of system icons is the feeling that they were designed based off children's toys. A good icon is a like a poem in its precision and simplicity.

**Note:** Alternative versions of a small number of icons are included in `/scalable/status` and the `Extra` directory.

\* To see the original icons being replaced, explore `/usr/share/icons`.
