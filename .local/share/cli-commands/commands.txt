This is a reference, not a script. Replace uppercase placeholders with your values; copy only the command, not its category or description. Quote paths containing spaces or shell metacharacters. For a filename beginning with '-', use a path such as ./-name, or '--' where the command supports it. A trailing backslash joins the next line into the same command.

Legend:

core   expected in the standard Fedora Sway Atomic image
shell   Bash builtin, shell syntax, or terminal key binding
atomic   correct image-based/Atomic workflow
opt   additional tool; check whether its package is installed

Custom images and package removals change availability. Use "command -v NAME" to check your installation; "man NAME" documents its installed version.

Privilege:

Commands beginning with sudo require an account authorized to use sudo. Some read-only commands also need privileges, especially device probes, SELinux policy-store queries, and system/audit logs. Process inspection may omit other users' details without sudo. SELinux policy can restrict root too. rpm-ostree uses polkit, so an authorized administrator may sometimes be prompted without sudo; sudo is shown for host changes for clarity. NetworkManager, firewalld, and power controls may also use polkit. If your daily account cannot use sudo, run privileged host commands from your admin account. Run --user, Flatpak, Podman, and Sway commands as the intended user.

Atomic rule:

Do NOT use "dnf install" to modify the host OS. Use Flatpak for desktop applications, Toolbx for mutable CLI/development environments, and rpm-ostree package layering only when host integration is actually required. /usr is read-only in the normal rpm-ostree deployment.

COMPRESSION AND ARCHIVES
────────────────────────
gzip, bzip2, and xz replace their input on success; add -k to keep it. tar keeps its input files. Extract archives into a suitable directory: extraction can overwrite existing files.

tar cf ARCHIVE.tar FILES              core   create tar archive
tar tf ARCHIVE.tar                    core   list tar archive contents
tar xf ARCHIVE.tar                    core   extract tar archive
tar czf ARCHIVE.tar.gz FILES          core   create gzip-compressed tar archive
tar xzf ARCHIVE.tar.gz                core   extract gzip-compressed tar archive
tar cjf ARCHIVE.tar.bz2 FILES         core   create bzip2-compressed tar archive
tar xjf ARCHIVE.tar.bz2               core   extract bzip2-compressed tar archive
bzip2 FILE                            core   compress FILE to FILE.bz2
bzip2 -d FILE.bz2                     core   decompress FILE.bz2
tar cJf ARCHIVE.tar.xz FILES          opt   create xz-compressed tar archive; requires xz
tar xJf ARCHIVE.tar.xz                opt   extract xz-compressed tar archive; requires xz
gzip FILE                             core   compress FILE to FILE.gz
gzip -d FILE.gz                       core   decompress FILE.gz
xz FILE                               opt   compress FILE to FILE.xz
xz -d FILE.xz                         opt   decompress FILE.xz
zip -r ARCHIVE.zip DIR                core   create ZIP archive
unzip ARCHIVE.zip                     core   extract ZIP archive


BUILDING FROM SOURCE
────────────────────
In the project directory, preferably inside Toolbx:

./configure                           opt   configure an Autotools source tree
make                                  opt   build a project with a Makefile
make DESTDIR="$PWD/stage" install     opt   install beneath ./stage when the project supports DESTDIR
cmake -S . -B build                   opt   configure a CMake project
cmake --build build                   opt   build a CMake project
meson setup build                     opt   configure a Meson project
meson compile -C build                opt   build a Meson project

Important:

Do not use an ordinary "sudo make install" to write into /usr on the Atomic host. Build/install mutable development software inside Toolbx, or use a documented user-local prefix such as ~/.local when the project supports it.
