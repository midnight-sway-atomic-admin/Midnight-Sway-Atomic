# Mindmapper

A self-contained, offline mind-mapping app that runs entirely in the browser.

![Mindmapper preview](mindmapper-preview.png)

## Features

- Create, move, edit, color, lock, and align idea cards.
- Add sticky notes anywhere on the canvas.
- Connect cards with straight or curved lines, optional arrows, and line notes.
- Automatically align nearby cards and equalize spacing.
- Center or ragged-right card text.
- Light, dark, and grayscale themes.
- Zoom, pan, fit-to-view, undo, and redo.
- Local autosave in the browser.
- Import and export editable maps as JSON.
- Export maps as scalable SVG images.

## Use

Open the HTML file in a modern browser. No installation, server, or internet connection is required.

Maps autosave locally in that browser on that device. For portable backups, use **Export → Editable map (JSON)** and import the file again when needed.
